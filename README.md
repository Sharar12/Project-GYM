# Project GYM

A full-stack gym management project built as a web application with a PHP/MySQL backend and a traditional HTML/CSS frontend.

## Overview

Project GYM is focused on managing gym members, accounts, plans and administrative operations from a browser-based system. The repository contains both public-facing pages and PHP-driven management screens.

## Main Areas

- Member registration and member information
- Account/profile management
- Admin dashboard and administration flows
- Membership/package contact flows
- Static pages such as About and Blog
- PHP/MySQL database integration

## Technology

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript

## Project Structure

```text
Project-GYM/
├── *.php                  # Application and processing pages
├── *.html                 # Static/public pages
├── Source/                # Supporting source assets
└── README.md
```

## Running Locally

1. Install XAMPP, Laragon, or another PHP + MySQL environment.
2. Place the project inside the web server directory.
3. Start Apache and MySQL.
4. Configure the database connection used by the PHP files.
5. Import the required database/schema if it is included with your local copy.
6. Open the project through the local server URL.

## Notes

This is an earlier PHP/MySQL web project and is useful as a reference for traditional server-rendered application architecture.
